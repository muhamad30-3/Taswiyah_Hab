# إعداد مساعد المستندات الذكي

يستدعي مساعد الترجمة والتلخيص والمصطلحات، وكذلك OCR البصري الاختياري للصور، خدمة متوافقة مع واجهة Chat Completions. لاستخدام OCR البصري يجب أن يدعم النموذج المهيأ استقبال الصور. يلزم ضبط المتغيرات التالية في إعدادات بيئة خادم API أو في مخزن الأسرار لدى مزود الاستضافة:

| المتغير | الغرض | مثال |
| --- | --- | --- |
| `AI_API_BASE_URL` | عنوان API الأساسي، دون `/chat/completions` | `https://api.openai.com/v1` |
| `AI_API_KEY` | مفتاح الخدمة السري | لا تحفظه في المستودع أو في كود المتصفح |
| `AI_MODEL` | اسم نموذج يدعم Chat Completions لدى المزود | يحدده مزود الخدمة |
| `PORT` | منفذ خادم API | يحدده مزود الاستضافة عادة |
| `TRUST_PROXY` | اجعله `true` فقط عند تشغيل الخادم خلف reverse proxy موثوق يضبط عناوين forwarded | `true` |

يجب استخدام HTTPS عند الاتصال بمزود خارجي. يبقى OCR المحلي هو الافتراضي. لا تُرسل الصورة إلى مزود AI إلا بعد موافقة مستقلة على الصورة نفسها ثم الضغط على زر OCR البصري؛ يرسل التطبيق نسخة مضغوطة ومصححة إلى A4 عند اكتشاف الورقة، بحد أقصى 4 ميغابايت. لا يُرسل النص إلى أدوات AI إلا بعد موافقة منفصلة. حد النص 50,000 حرف، والحد المشترك 20 طلباً لكل عنوان IP في الساعة.

أثناء تطوير الواجهة، يوجّه Vite طلبات `/api` إلى `http://localhost:3000` افتراضياً؛ غيّر `API_SERVER_URL` عند الحاجة. في الإنتاج، اربط المسار `/api` بخادم API نفسه، واضبط متغيرات الأسرار في بيئة استضافة الخادم. إن لم تُهيأ بيانات المزود، يرد الخادم برسالة صريحة بأن خدمة AI غير مهيأة.
